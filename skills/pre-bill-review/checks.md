# Pre-bill checks in detail

> **Customize this file.** Adjust the thresholds to your firm's policies. Client-specific limits belong in the `client-billing-guidelines` skill, not here.

## Duplicates

- Same timekeeper, same date, same or near-identical narrative: likely duplicate.
- Two or more timekeepers billing the same meeting, call, deposition, or hearing: check whether the client allows more than one attendee.
- Same narrative repeated across many days with identical time: ask whether it's a recurring task or copied entries.

## Staffing

- Count timekeepers who billed the matter in the period, by role. Compare with the client's staffing rule, if there is one.
- Flag partners billing tasks typically done by associates or paralegals (document review, cite-checking, organizing productions). This is a question for the billing attorney, not a violation.
- Flag new timekeepers on the matter, which some clients don't pay to bring up to speed.

## Unusual time

- An entry more than twice the typical time for the same task type on this matter.
- More than 12 hours in a day for one timekeeper across all entries you can see.
- Round-number patterns across many entries (for example, many entries of exactly 1.0 or 2.0) can suggest estimated time. Mention it gently.

## Late time

- If entry dates are available, flag time entered more than 30 days after the work date, or the client's limit if it's shorter.

## Codes

- Required codes missing.
- Task code doesn't fit the narrative (for example, a deposition outline coded as written discovery).
- Activity code doesn't fit (for example, a client call coded as research).
